# Maze Runner

A simple yet engaging maze game built with vanilla HTML, CSS, and JavaScript. Navigate through the maze to reach the blue target!

## Features

*   **Diffculty Levels**: Choose between Easy (10x10), Medium (20x20), and Hard (30x30) mazes.
*   **Random Maze Generation**: Every game creates a unique maze using a depth-first search algorithm.
*   **Responsive Design**: Playable on desktop and mobile devices.
*   **Two Control Schemes**: Use your keyboard arrow keys or the on-screen buttons to move.

## How to Play

1.  Clone the repository or download the source code.
2.  Open `index.html` in your web browser.
3.  Select a difficulty level from the dropdown menu.
4.  Click the **Start** button to generate a new maze.
5.  Guide the **Red Dot** (Player) to the **Blue Dot** (Goal).

## Controls

*   **Desktop**: Use the Arrow Keys (⬆️, ⬇️, ⬅️, ➡️) to move.
*   **Mobile/Mouse**: Use the on-screen directional buttons.

## Technologies Used

*   **HTML5**
*   **CSS3** (Flexbox, Responsive Media Queries)
*   **JavaScript** (Canvas API)
